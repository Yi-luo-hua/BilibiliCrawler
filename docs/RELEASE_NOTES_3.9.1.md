# BilibiliCrawler v3.9.1

本次更新改善词云清晰度、配色和桌面布局。

## 高清词云与复古宝石配色

- 新生成的词云以 4 倍比例渲染，输出分辨率从 800 × 440 提升至 3200 × 1760 像素，改善在分析结果窗口中放大查看时的清晰度。
- 保留原有词频和排版网格，默认使用 CARTO Prism「复古宝石」11 色配色，包含紫、蓝、青、绿、金黄、橙和红等冷暖色。
- 颜色分配采用独立固定随机种子，使相同词频的呈现可复现。历史结果中的旧图片需重新生成后才会应用本次调整。

## 桌面布局

- 默认窗口由 1280 × 820 调整为 1440 × 960，最小窗口尺寸仍为 900 × 720。
- 登录按钮文字保持单行，调整水平内边距并避免图标被挤压。

## 下载与验证

GitHub Release 提供 Windows x64 安装包、安装包 SHA-256、后端文件清单，以及 Python wheel/sdist 和校验文件。应用版本统一为 3.9.1。升级前请退出程序并运行安装包。

构建和验证范围记录在 [v3.9.1 发布记录](https://github.com/Yi-luo-hua/BilibiliCrawler/blob/main/docs/RELEASE_3.9.1.md)。Windows 安装包未签名。
