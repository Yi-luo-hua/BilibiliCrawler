# v3.6.0 桌面候选版

本版尚未公开发布。

- 左上角应用名称下显示当前版本，替代原来的“评论 / 动态”。桌面窗口读取安装版本，浏览器预览读取 Cargo 项目版本。
- 侧栏提供手动检查更新、更新说明，以及黑色磨砂底、黄色星星与手写字形的 Star 按钮；点击 Star 打开项目 GitHub 页面，由用户在 GitHub 完成点星。
- 检查 GitHub 最新正式版本；按数字比较版本，不提示降级。
- 有匹配的 Windows x64 安装包时，可在默认浏览器下载安装包。下载后退出应用并运行安装程序完成更新；本版不提供静默安装或自动重启。
- 当前任务运行期间禁用安装包下载入口。网络超时、访问限流、无公开版本、安装包尚未上传等情况显示明确提示，可重试。

更新源为 `Yi-luo-hua/BilibiliCrawler` 的 GitHub Releases。只有名称、版本和下载地址均匹配的已上传安装包才提供直接下载入口。

## 构建与验证

Windows x64 NSIS 安装包使用 CPython 3.13.15 和锁定依赖构建。应用版本统一取自 `desktop/src-tauri/Cargo.toml`。

当前包为本地候选产物。自动化检查与构建结果不能代替真实桌面交互、已有安装覆盖升级及用户数据保留验收。
