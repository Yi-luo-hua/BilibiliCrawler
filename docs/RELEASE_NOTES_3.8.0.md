# BilibiliCrawler v3.8.0

本版新增分析结果大屏，完整显示分析正文，并改进长主题标签和图表导出。

## 分析结果大屏

- 分析完成后自动打开接近全屏的结果窗口，配置页保留“查看结果大屏”入口。
- 支持关闭按钮、Esc 和点击窗口外的遮罩关闭，关闭后恢复焦点；点击窗口内部空白不会关闭。
- 重复同步同一份结果不会重新弹出。总结、指标、图表、深入剖析、自定义分析和分析要点保持原有顺序、配色与玻璃质感。

## 完整内容与图表

- 桌面结果不再截断总结、要点、洞察、风险、代表性评论、深入剖析或自定义分析，完整保留列表条目及段落换行。
- 主题名称按 Unicode 字符换行，长标签增加行间距；桌面主题图和导出 SVG 均保留全部主题。
- 时间趋势 SVG 保留全部日期及早期峰值，跨月分析的导出与页面数据一致。
- 中英文 MCP 配置示例使用明确的 Cookie 占位符和 Windows 支持的路径格式。

## 下载与验收范围

Windows x64 安装包、SHA-256 校验文件、安装包内容清单及 Python wheel/sdist 随本次 GitHub Release 提供。升级桌面端时请退出应用并运行新安装包。

本版没有修改爬取节奏、LLM 超时或重试策略。自动化、构建与产物验证结果，以及真实接口、LLM 和桌面安装未覆盖的路径，记录在 [v3.8.0 发布记录](RELEASE_3.8.0.md)。Windows 安装包未做代码签名。
